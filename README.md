# Sistema-de-Controle-de-Livros
Sistema de gerenciamento bibliotecário desenvolvido em **C**, focado na otimização do controle de acervo e no cadastro de usuários. O projeto utiliza persistência de dados através de arquivos de texto (`.txt`), permitindo que as informações sejam salvas e carregadas a cada execução.


## 🛠️ Tecnologias Utilizadas
* **Linguagem:** C
* **Compilador:** GCC (MinGW)

 ## ✨ Funcionalidades
* **Gerenciamento de Acervo:** 
  * Adicionar novos livros.
  * Buscar livros por código.
  * Listar todos os livros cadastrados.
* **Gerenciamento de Usuários:**
  * Cadastrar novos usuários (nome, matrícula e curso).
  * Buscar usuário específico pela matrícula.
  * Listar todos os usuários cadastrados.

## 🚀 Como Compilar e Executar
- Certifique-se de ter o compilador GCC, instalado no seu ambiente
- Compile: gcc main.c arquivo.h -o nome_executavel 
- Execute: .\nome_executavel.exe
